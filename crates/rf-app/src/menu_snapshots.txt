# The right-click menu as the hand-written ctx_menu.rs built it, one case per context (label, icon, shortcut hint).
# "-" is a separator, " >" after a label is a submenu. Recorded from the old functions before they were converted
# (read off the code line by line: the old builders need a live folder view, so they cannot be run in a test).
# The quick buttons at the top of the menu and the contents of submenus are not part of it.
